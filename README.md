# Парсер prosemena.ru → Excel

Собирает карточки товаров с prosemena.ru по культурам, сохраняет по одному
JSON на культуру и генерирует Excel (`.xlsx` / `.xls` / `.csv`).

## 1. Подготовка виртуального окружения

**Windows PowerShell:**

```powershell
cd C:\Users\lion_\learn\ggit\parsing_prosemena.ru\parsing_semena
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## 2. Парсинг ссылок

main.py — листает категории из CATALOG_URLS, открывает карточки,
раскладывает по культурам и пишет json_data/<culture>.json.

```powershell
python main.py
Результат: json_data/amarant.json, json_data/gorokh.json, …
```

Настройки в шапке main.py: REQUEST_DELAY, CATALOG_DELAY,
MAX_PAGES_PER_CATALOG.

## 3. Генерация Excel

make_xlsx.py — берёт все json_data/\*.json и пишет
xlsx_data/<имя>.xlsx. Одна строка = одна культура.

```powershell
python make_xlsx.py # авто: xlsx → xls → csv
python make_xlsx.py --xlsx # современный Excel (2007+)
python make_xlsx.py --xls # старый Excel (2003)
python make_xlsx.py --csv # универсальный CSV
```

## 4. Генерация Word (.docx) по шаблону

**`main_articles_word.py`** — берёт список статей из `articles_links.txt`,
открывает каждую, вытаскивает тело статьи и вставляет в шаблон
`templates_new.docx`, сохраняя оформление шаблона (шапка, подвал, стили).
Результат — `articles_docx/<slug>.docx`.

### Что делает

- Читает URL из `articles_links.txt` (по одному в строке).
- Открывает `templates_new.docx` (должен быть **настоящим** `.docx`, не `.doc`).
- Заменяет:
  - `{{TITLE}}` → заголовок статьи;
  - `{{BODY}}` → тело статьи (заголовки, абзацы, списки, цитаты, таблицы).
- Если `{{TITLE}}`/`{{BODY}}` в шаблоне нет:
  - заголовок вставляется первым абзацем,
  - тело — дописывается в конец документа.
- Сохраняет в `articles_docx/<slug>.docx`.

### Форматирование

| Элемент                              | Шрифт           | Размер        | Оформление                                                     |
| ------------------------------------ | --------------- | ------------- | -------------------------------------------------------------- |
| Основной текст (`Normal`)            | Times New Roman | 14pt          | по ширине, красная строка 1.25 см, интервал между абзацами 3pt |
| Заголовки (`Heading 1/2/3`, `Title`) | **Arial**       | 18/15/13/22pt | по центру, жирные, **без переносов**, без красной строки       |
| Курсив (`blockquote`)                | **Arial**       | 11pt          | курсив, красная строка 1.25 см, без сдвига влево               |
| Списки (`ul`/`ol`)                   | Times New Roman | 14pt          | маркер/номер, отступ 18pt, без красной строки                  |
| Таблицы                              | Times New Roman | 12pt          | рамки, по левому краю, без красной строки, без интервалов      |

Автоматическая расстановка переносов включена для текста (не для заголовков).

Картинки из статьи **не вставляются**. Меню, шапка, подвал, сайдбары и блок
«Еще статьи на эту тему» с сайта не попадают — берётся только `.b-content`.

### Требования к `templates_new.docx`

- Формат: **`.docx`** (не `.doc` 97-2003!). Если у вас `.doc` — откройте в Word
  и «Сохранить как → Документ Word (\*.docx)».
- Плейсхолдеры `{{TITLE}}` и `{{BODY}}` — по желанию. Если нет, скрипт
  вставит заголовок и тело в начало/конец документа, сохранив шапку и подвал.
- Шрифты шаблона переопределяются скриптом (Arial для заголовков, TNR для
  текста) — но стили шапки/подвала/логотипа остаются как в шаблоне.

### Запуск

```powershell
.\venv\Scripts\Activate.ps1
python main_articles_word.py
```

## 5. Печать книгой (`booklet.py`)

**`booklet.py`** — генерирует ряд страниц для печати документа «книгой»
(booklet / imposition). Не парсит сайт, не читает JSON — просто считает
порядок страниц по числу `N`.

### Что делает

Принимает **число страниц** аргументом и выдаёт:

- **ряд для печати** — порядок, в котором страницы должны идти на принтер;
- **разбивку по сторонам листов** (левая | правая);
- **разбивку по листам** (лицо + оборот);
- **ряд одной строкой** для копирования.

Нечётное `N` (или не кратное 4) добивается до ближайшего кратного 4
**одной и той же** страницей-заглушкой (по умолчанию `N+1`).

### Схема брошюры

- **Лист 1** — обложка снаружи (страницы `N` и `1`);
- **следующий лист** — `N-2` и `3`;
- **…**;
- **самый внутренний лист** — пара из середины.

Листы складываются **стопкой пополам**, лист 1 — снизу (обложка).

### Использование

```powershell
python booklet.py 12                # 12 страниц, 3 листа
python booklet.py 8                 # 8 страниц, 2 листа
python booklet.py 10                # добивает до 12, заглушка = 11
python booklet.py 10 --blank 10     # добивает до 12, заглушка = 10 (последняя реальная)
python booklet.py                   # без аргумента — спросит число
```
